## Build Clouds

### Purpose
This folder holds **implementation-driving briefs** (“clouds”) for major build efforts:
- concise but deep specs
- rationale + constraints (ethos + invariants)
- scope and non-goals
- key contracts and acceptance criteria

These docs are meant to be usable by:
- a coding agent
- a planning agent
- a future human maintainer

### Rules of thumb
- **Prefer stable contracts over vibes**: define the seams, states, and reason codes.
- **Artifacts are truth**: link to canonical artifacts/paths instead of duplicating blobs.
- **Keep it weight-bearing**: store what prevents repeated mistakes and misalignment.
