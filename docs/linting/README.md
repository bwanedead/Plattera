# Linting & Static Governance

This folder documents the repo's linting and lint-adjacent policy checks.

## Purpose
- Explain the difference between generic linting and repo-specific governance.
- Provide one stable place to find the custom rules, commands, and rollout intent.

## Documents
- `static-governance.md`: current automated policy layer, what it enforces, where it runs, and how to extend it safely.

## When to read this folder
- Before changing lint, typecheck, or CI policy.
- Before adding a new custom repo rule.
- When a governance check fails and you need the reason behind the policy.
