# MAPDEP-BR-040 point-anchored evidence-window judgment ledger

Date: 2026-09-21
Surfaces: procedural guidance v48→v49.
Tool specs: two behavioral sentences that mandated `small_plus` as the ordinary starting shape were qualified so they no longer contradict the procedural judgment. Wire grammar stays in the tool spec.
Unchanged versions: branch, dossier driver, startup context, delegate profiles, harness trunk.

## Why the centered-template default changed

Live teaching treated a centered `small_plus` window as the ordinary first packet and treated resizing as something that could happen later. When context was asymmetric, wrapped, or edge-constrained, delegates then reported clipped or insufficient packets and the parent spent waves nudging the same pocket. BR-039 already lets the agent keep the point and state independent extents. This pass teaches when to use that capability. It does not select geometry, force extents, cap retries, or weaken atom-level accountability.
